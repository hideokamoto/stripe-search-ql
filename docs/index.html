Stripe Search API の
クエリを型安全に組み立てる

stripe-search-ql は、Stripe Search API のクエリ文字列をフルーエント API で構築できる TypeScript ライブラリです。手書きの文字列連結から解放され、読みやすく保守しやすいコードを書きましょう。

GitHub で見る コード例を見る
$ npm install stripe-search-ql

Problem & Solution

手書きのクエリ文字列、まだ続けますか?

Stripe Search API のクエリは独自の構文を持ちます。文字列を手動で連結すると、エスケープ漏れ・構文ミス・可読性の低下に繋がります。stripe-search-ql を使えば、メソッドチェーンで意図が明確なクエリを組み立てられます。

✗ Before: 手書きの文字列連結
// エスケープは正しい? AND の前後のスペースは?
// metadata の括弧記法、覚えていますか?

const query =
  `email:"${email}"` +
  ` AND ` +
  `metadata["plan"]:"${plan}"` +
  ` AND ` +
  `amount>` + minAmount;

// => 実行時まで構文エラーに気づけない
✓ After: stripe-search-ql
import { stripeQuery } from "stripe-search-ql";

const query = stripeQuery()
  .field("email").equals(email)
  .and()
  .metadata("plan").equals(plan)
  .and()
  .field("amount").greaterThan(minAmount)
  .build();

// => 自動エスケープ・型チェック・構文保証

Features

開発者に嬉しい設計

Stripe 決済システムの検索ロジックを安全かつ効率的に構築するための機能を備えています。

🔗

フルーエント API

メソッドチェーンで直感的にクエリを組み立て。field(), and(), build() のシンプルな流れで、複雑な検索条件も読みやすく表現できます。

🛡

型安全 & 自動バリデーション

TypeScript の型推論によるコード補完に加え、AND/OR の混在禁止・部分一致の最小文字数チェックなどを実行時に検証します。

🔍

自動エスケープ

文字列値のダブルクォートやバックスラッシュを自動でエスケープ。メタデータキーの括弧記法も正しく生成されるため、構文エラーを防ぎます。

📦

ゼロ依存

ランタイム依存なし。バンドルサイズへの影響を最小限に抑えつつ、必要な機能をすべて提供します。

🎯

専用ビルダー & テンプレート

CustomerQueryBuilder や chargeTemplates など、リソースごとのヘルパーを提供。よくあるクエリパターンをワンライナーで記述できます。

⚖

MIT ライセンス

商用利用を含むあらゆるプロジェクトで自由に使えます。ソースコードは GitHub で公開されています。

Code Examples

実践的なコード例

Stripe Search API が対応する主要な検索パターンを、stripe-search-ql でどう書くかを紹介します。

顧客をメールアドレスで検索する

CustomerQueryBuilder を使えば、フィールド名を覚える必要がありません。

import { customerQuery } from "stripe-search-ql";
import Stripe from "stripe";

const stripe = new Stripe(process.env.STRIPE_SECRET_KEY!);

const query = customerQuery()
  .email().equals("user@example.com")
  .build();
// => 'email:"user@example.com"'

const result = await stripe.customers.search({ query });

金額の範囲と通貨で課金を絞り込む

between() を使った範囲検索と AND 条件の組み合わせ。

import { stripeQuery } from "stripe-search-ql";

const query = stripeQuery()
  .field("amount").between(1000, 50000)
  .and()
  .field("currency").equals("jpy")
  .build();
// => 'amount>=1000 AND amount<=50000 AND currency:"jpy"'

メタデータで検索する

metadata() メソッドが括弧記法やエスケープを自動処理します。

const query = stripeQuery()
  .metadata("order-id").equals("ORD-2025-001")
  .and()
  .notMetadata("refunded").isNull()
  .build();
// => 'metadata["order-id"]:"ORD-2025-001" AND -metadata["refunded"]:null'

テンプレートで定型クエリを素早く生成

chargeTemplates で、よくある検索パターンを 1 行で。

import { chargeTemplates } from "stripe-search-ql";

// 過去 7 日間に失敗した課金
const failedQuery = chargeTemplates.failedInLastDays(7).build();

// 高額課金 (100,000 以上)
const highValueQuery = chargeTemplates.highValue(100000).build();

// 通貨で絞り込み
const usdQuery = chargeTemplates.byCurrency("usd").build();

今すぐ使い始める

npm からインストールして、数行のコードで Stripe Search API のクエリを安全に構築しましょう。
